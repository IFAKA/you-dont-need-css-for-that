# Accessibility Checks

After an HTML-first rewrite, verify:

- correct native role and semantics
- accessible names
- keyboard operation
- focus order
- visible focus
- heading hierarchy
- list/table relationships
- form labels and grouping
- disabled/readonly semantics
- disclosure state where applicable
- zoom and reflow
- forced-colors/high-contrast behavior
- comprehension with author CSS disabled

Do not trade accessibility for fewer CSS rules.
