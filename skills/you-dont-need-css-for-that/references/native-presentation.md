# Native Presentation

Browsers ship user-agent styles for many semantic elements. These defaults can remove CSS in low-design or content-heavy contexts, but they are not a universal design system.

## Good use cases

- prototypes
- internal tools
- documentation
- low-maintenance utilities
- progressive-enhancement baselines
- forms where native controls are acceptable

## Risks

- cross-browser visual differences
- platform-specific control rendering
- inconsistent spacing
- insufficient brand alignment
- density mismatch
- product requirements that demand a controlled visual system

Treat native presentation as an explicit product tradeoff, not as inherently superior styling.
