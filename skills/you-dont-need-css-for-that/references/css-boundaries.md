# CSS Boundaries

CSS is still the correct layer for:

- general layout
- Grid and Flexbox composition
- spacing systems
- typography systems
- color and theming
- responsive design
- container queries
- visual density
- deliberate hierarchy beyond semantic defaults
- animation and transitions
- decorative effects
- brand identity
- visual state treatment
- print styling

Do not move these concerns into HTML merely to reduce stylesheet size.

The skill should remove CSS only when better HTML makes the CSS genuinely redundant.
